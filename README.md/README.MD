# Python Beginner Exercises & Programs

A collection of foundational Python scripts covering basic algorithms, arithmetic operations, and user input handling.

## Programs Included

1. `armstrong_number.py`: Checks whether a given number satisfies the Armstrong condition.
2. `average_marks.py`: Calculates and displays the average marks across three subjects.
3. `celsius_to_fahrenheit.py`: Converts temperature readings from Celsius to Fahrenheit.
4. `time_converter.py`: Decomposes seconds into standard time units and calculates equivalent planetary days.

## How to Run

Run any file with Python 3:

```bash
python armstrong_number.py
python average_marks.py
python celsius_to_fahrenheit.py
python time_converter.py
